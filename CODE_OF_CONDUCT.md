# Code of Conduct

This project adopts the [Contributor Covenant](https://www.contributor-covenant.org/),
version 2.1. By participating, you are expected to uphold this code.

In short: be respectful, welcoming, and considerate. Harassment and exclusionary
behaviour are not tolerated.

Report unacceptable behaviour to the repository maintainer. The full text is
available at <https://www.contributor-covenant.org/version/2/1/code_of_conduct/>.
